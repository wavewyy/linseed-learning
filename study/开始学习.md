## 方法一：先双击跑一遍（最简单）

1. 打开 Windows 文件资源管理器，进入 `D:\single cell项目\Linseed`。
2. 双击 `run_quickstart.cmd`。这是本次添加的运行入口。
3. 会出现一个窗口，自动用 R 执行 `study\01_quickstart.R`。等待它完成，不要中途关窗口。
4. 看到 `QUICKSTART_OK` 和 `SUCCESS` 表示运行完成。按任意键关闭窗口。
5. 打开 `results\quickstart\proportions.png` 看图；`proportions.csv` 是数值结果。

每次运行会覆盖 quickstart 文件夹内同名结果。如果需要保留自己的结果，请先复制该文件夹。

## 方法二：在 VS Code 中逐段学习（推荐）

### 1. 打开正确的工作区

在资源管理器中双击 `D:\single cell项目\Linseed\Linseed.code-workspace`。
如果之前 VS Code 还开着旧位置的项目，关闭旧窗口，使用这个新打开的窗口。
若询问是否信任文件夹，确认这是你自己的 Linseed 项目后选择信任。
左边展开 `study`，点击 `01_quickstart.R`。

### 2. 打开一个 R 终端

“终端”是输入命令、查看执行结果的区域。这里需要启动 R，让它能理解 R 语言。

用鼠标操作：
1. 点击 VS Code 顶部菜单 **查看（View）**。
2. 点击 **命令面板…（Command Palette…）**。窗口上方出现一个输入框。
3. 在输入框中输入 `R: Create R terminal`。输入 `R: Create` 也可以。
4. 点击匹配的 **R: Create R terminal**，或者用方向键选中后按 Enter。
5. 下方应出现 R 的版本信息，最后出现 `>`，表示 R 已准备好接收代码。

`Ctrl+Shift+P` 只是上述第 1、2 步的快捷方式：按住 Ctrl 和 Shift，再按一下 P，随后松开。不是把这些字符输入代码文件，也不是在终端里输入这句话。

如果搜索不到该命令：先确认已经打开 `01_quickstart.R`；再点击左侧扩展图标（四个小方块），搜索 `REditorSupport.r`，确认 R 扩展已启用，然后重启 VS Code。

### 3. 先整体运行，确认成功

在下方显示 `>` 的 R 终端中，粘贴下面这一行，再按 Enter：

```r
source("D:/single cell项目/Linseed/study/01_quickstart.R", encoding="UTF-8")
```

等待出现 `QUICKSTART_OK: results/quickstart`，并重新回到 `>`。
脚本将图保存为文件，不一定自动弹出图片窗口。请到 `results\quickstart` 中打开 `proportions.png`。

### 4. 再逐段执行，理解每一步

回到上方 `01_quickstart.R` 编辑区域，从文件开头开始：
1. 用鼠标选中一行或一段完整代码。
2. 按住 Ctrl，再按 Enter。所选代码会发送到下方的 R 终端执行。
3. 看下方结果，然后继续下一段。以 `#` 开头的行是注释。

第一次务必先执行 `.libPaths(...)`、`setwd(...)` 和 `library(linseed)` 等准备代码。
创建 `lo` 后，可以在 R 终端输入 `lo` 查看对象；完成解卷积后输入 `lo$proportions` 查看比例矩阵。
多行函数调用要把整段（含右括号）一起选中。如果提示符变为 `+`，表示 R 正等待剩余代码；误操作时按 Esc 或 Ctrl+C 取消后，重新发送完整代码。

## 方法三：在 PowerShell 终端运行

VS Code 顶部点击 **终端 → 新建终端**。如果提示符类似 `PS D:\...>`，这是 PowerShell。
粘贴以下完整命令，按 Enter：

```powershell
& "D:\single cell项目\Linseed\R\bin\Rscript.exe" "D:\single cell项目\Linseed\study\01_quickstart.R"
```

路径中有空格，因此保留双引号和开头的 `&`。
不要把这条 PowerShell 命令粘贴到显示 `>` 的 R 终端里；同样，不要把 `source(...)` 直接粘贴到 PowerShell 里。

## 目录及维护

`R` 是运行环境；`rtools45` 是编译工具；`library` 是 R 包库；`source` 是官方源码；`study` 是学习材料；`results` 是结果；`logs` 是日志。

日常学习不用运行 install.R。只有需要重装依赖时，在 PowerShell 中执行：

```powershell
& "D:\single cell项目\Linseed\R\bin\Rscript.exe" "D:\single cell项目\Linseed\install.R"
```

当前配置对应上述位置。如果再次移动整个目录，需要再次更新路径。编译安装还可能受中文和空格路径影响；现有已编译包的运行以本次实际验证为准。
